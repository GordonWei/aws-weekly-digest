# No third-party dependencies.
# Everything runs on the Python standard library plus boto3, which the Lambda
# runtime already ships.
#
# Standard library used:
#   urllib.request  — fetching the RSS feeds
#   xml.etree       — XML / RSS parsing
#   html            — HTML entity decoding
#   re              — regex work
#   json            — request/response payloads
#   os              — reading environment variables
#   datetime        — date arithmetic
#
# AWS SDK (bundled with the Lambda runtime, nothing to package):
#   boto3           — Bedrock / SES / S3 / SSM
