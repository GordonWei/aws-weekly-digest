#   re              — Regex 處理
#   json            — Bedrock API payload
#   os              — 環境變數讀取
#   datetime        — 日期計算
#
# AWS SDK（Lambda 內建，不需打包）：
#   boto3           — Bedrock / SES / S3 / SSM
